## Статусы

| Значок | Значение |
|---|---|
| ⬜ | Open — не начато |
| 🔧 | In progress |
| ✅ | Fixed — исправлено (указать дату и commit) |
| 🚫 | Won't fix / не актуально |
| ❓ | Невоспроизводимо статически (требует запуска/эксперимента) |

Правила работы:

1. Взял задачу → меняешь статус на 🔧.
2. Исправил → ✅ + строка в [логе исправлений](#лог-исправлений) (дата, ID, что сделано, commit).
3. Решил не чинить → 🚫 + одна строка причины прямо в комментарии строки таблицы.
4. Нашёл новый баг → добавляешь строку `N…` (сквозная нумерация) в раздел «Новые баги»;
   в уровневые таблицы новые баги не расселяются.

Связанное наблюдение по данным (не код): калибровка `exp_2/calibration_2.yaml` подозрительна
(fx≈8500 px @ 1280 ширины ⇒ hFOV≈8.6°, cy<0 у обеих камер, k2=-22 у C2) при z≈1350±100 мм
в облаках — частичное вырождение. Усиление (ревизия 24.7 аудита): cx камеры C2 «плавает»
между экспериментами при той же оптике — exp_1: 975.9 → exp_2: 578.2 (сдвиг ~398 px),
несогласованно с C1 — настоящий principal point так двигаться не может. Вывод: интринсики
exp_2 **не интерпретировать физически**; отрицательный cy здесь — вероятный симптом слабо
обусловленной оценки (в отличие от общего случая 24.7). Идея фикса: флаг деградации в
solver/валидации («cy вне кадра у обеих камер или |k2|≫1»). Решается экспериментом 26.5
аудита (геометрическая валидация по ChArUco на holdout-кадрах).

Контекст облаков exp_2/clouds (замер 2026-08-27): 59 233 PLY, точек в кадре 12–357
(median 20), z = 1233–1465 мм (median ≈1318) — согласуется с базой рига ~1.4 м и
наглядно демонстрирует монотонное вымирание треков (12.5). Числа же §18 аудита
относятся к удалённому прогону `forma-veridica/point_clouds/` (12 518 PLY, frame_step=5) —
только структурные выводы §18 переносимы.
